# Accessibility

Supported in v1:

- **Reduced motion.** The settings toggle and `prefers-reduced-motion` remove CSS
  animation and transitions. The juice layer disables shake, vignette pulses and
  slow motion; hit flash and damage numbers stay because they carry information.
- **UI scale.** Menu panels scale from 80% to 150% through `--cb-ui-scale`.
- **Keyboard menus.** Every menu control is a native button with a text label and
  a visible focus ring. The in-match surface is pointer-locked by design; touch
  and desktop controls are documented in the README.
- **Remapping.** Ten game actions can be assigned one key each.
- **Team colours.** The palette is blue/orange, which remains separable for the
  common red-green deficiencies. Colour is not the only cue: team labels and
  core HP text are present in the HUD.
- **Contrast.** HUD labels are measured against their composited panel in
  `tests/a11y.spec.ts`; the current pair is above 4.5:1. Re-run the spec after
  changing `hud.css`.

Not supported or not verified:

- Screen readers for the in-match HUD. Canvas content has no DOM equivalent yet.
- A fully audio-described experience.
- A device-specific accessibility audit on iOS or Android; see
  `DEVICE-MATRIX.md` once real devices are available.
- The 150% scale can force menu scrolling on a 320 px-wide viewport; controls
  remain reachable, but the layout is not redesigned for it.
- Keyboard access while the pointer is locked. Escape releases the lock and
  returns to the menu, which is the documented exit.
